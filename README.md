# HIDPad

iPhone を、Mac や Windows の Bluetooth マウス・キーボード・発表用クリッカーにするアプリ。個人利用を前提にしていて、App Store には出していない。

iPhone 自体が標準の Bluetooth LE HID デバイスとして振る舞う。接続先に受信用のソフトを入れる必要はない。

- 設計と、実機で確かめたことの記録：[docs/design.md](docs/design.md)
- この文書：使い方、入れ方、困ったときの対処

## できること

| 機能 | 内容 |
|---|---|
| トラックパッド | ポインタの移動、タップでクリック、指2本のタップで右クリック、ドラッグ、スクロール |
| キーボード | 修飾キー、矢印、Esc、Tab、F1〜F12、英数／かな、メディアキー、文字入力 |
| 日本語入力 | iPhone のフリック入力を、接続先の日本語入力（ローマ字入力）に写す |
| クリッカー | スライド送りと、iPhone を振って動かす PowerPoint のレーザーポインター |
| 複数の接続先 | Mac と Windows に同時につなぎ、送り先を切り替える |

## 必要なもの

- iPhone（iOS 17 以降。開発と確認は iPhone 17、iOS 27.3）
- Mac と Xcode（確認は macOS 27.2、Xcode 27.2）、xcodegen（`brew install xcodegen`）
- iPhone のデベロッパモードをオンにしておく（設定 > プライバシーとセキュリティ > デベロッパモード）
- iPhone と Mac を USB でつなぎ、iPhone のロックを解除しておく

## 入れ方

リポジトリの一番上のディレクトリで実行する。

```
scripts/build.sh      # プロジェクトの生成とビルド
scripts/install.sh    # iPhone へのインストール
scripts/launch.sh     # 起動。アプリの出力は App/build/run.log に記録される
scripts/stop.sh       # 終了
```

- 最初に `scripts/local.env.example` を `scripts/local.env` という名前でコピーし、対象の iPhone の UDID と、Apple の開発チーム ID を書く。`scripts/local.env` は git に入れない。
- UDID は `xcrun devicectl list devices` の Identifier 欄で分かる。スクリプトに `--udid <UDID>` を付けて指定することもできる。
- 署名は自動署名。バンドル ID（`dev.koukichi.hidpad`）は `App/project.yml` と `scripts/common.sh` にある。自分の環境で使うときは、自分のものに変える。
- インストールしたあとは、iPhone のホーム画面のアイコンからも起動できる。その場合、ログは記録されない。
- プロビジョニングプロファイルの期限が切れたら、同じ手順でビルドとインストールをやり直す。

初回の起動時に、Bluetooth の使用許可を求められる。「許可」を選ぶ。

## つなぎ方

### 同じ Apple ID の Mac

何もしなくてよい。iPhone でアプリを起動すると、Mac が 2 秒ほどで iPhone をマウス兼キーボードとして認識する。アプリを終了すると認識も消える。

- 「システム設定 > Bluetooth」の一覧には iPhone は出ない。つながっているかどうかは、アプリの画面上部の接続先の名前で分かる。
- **Mac の Bluetooth 設定で「このデバイスを削除」をしない。** iPhone と Mac の結び付きは、Apple 製品同士の連携と共通の可能性がある。

### Windows

1. iPhone でアプリを前面に出しておく
2. Windows の「設定 > Bluetooth とデバイス > デバイスの追加 > Bluetooth」を開き、`HIDPad` を選ぶ
3. iPhone と Windows の両方で、ペアリングを承認する

一度ペアリングすれば、次からは Windows の Bluetooth がオンで、アプリが動いていれば自動でつながる。

**以前その Windows と iPhone をペアリングしたことがある場合は、先に両方の古い登録を消す。** Windows で iPhone を削除し、iPhone の「設定 > Bluetooth」でも Windows の登録を解除する。片方に残っていると、Windows は iPhone を電話として認識し（「その他のデバイス」に分類される）、入力機器として働かない。

### 送り先の切り替え

画面上部の接続先の名前を押すと、つながっている接続先の一覧が出る。選んだ接続先だけに入力を送る。ほかの接続先があとからつながっても、送り先は勝手には変わらない。

接続先の名前、ポインタの速さ、キー配列などは、接続先ごとに覚えている（設定 >「接続先の管理」）。

## 使い方

### トラックパッド

| 操作 | 動き |
|---|---|
| 指1本で動かす | ポインタの移動 |
| タップ | 左クリック |
| 指2本でタップ | 右クリック |
| タップした直後にもう一度触れて動かす | ドラッグ |
| 下の左右の丸いボタン | 左ボタン、右ボタン。押したまま別の指で動かすとドラッグ |
| 右端の帯を上下になぞる | スクロール。払って離すと慣性で続く |
| 指2本で動かす | スクロール（縦と横） |

下段の丸いボタンは、前の曲、再生／一時停止、次の曲、音量を下げる、音量を上げる。

### キーボード

中央のキーボードのボタンを押すと、キーのパネルが出る。上のタブで切り替える。

- **キー**：Esc、Tab、英数、かな、削除、矢印、Home／End、Page Up／Down、Return、Space
- **Fn**：F1〜F12
- **文字入力**：iPhone のキーボードで打った文字を送る
- **メディア**：再生や音量など

修飾キー（shift、control、option、command）は、1回押すと次の1キーだけに効き、2回続けて押すと固定される。もう一度押すと解除される。caps の点は、接続先の Caps Lock の状態を表す。

### 文字入力と日本語

「文字入力」のタブを開くと、iPhone のキーボードが出る。

- **英語キーボード**：打った文字がそのまま接続先に入る。
- **日本語フリックキーボード**：打ったかなを、ローマ字のキー操作に直して送る。接続先の日本語入力がそれをかなに戻し、変換する。

| iPhone での操作 | 接続先での結果 |
|---|---|
| かなを打つ | 変換中のかなが伸びる |
| 「空白」 | 変換、次の候補 |
| 「確定」「改行」 | 確定 |
| 候補をタップ | 接続先が同じ読みを変換して表示する。確定はしない |

知っておくこと：

- **接続先の日本語入力は、ローマ字入力にしておく。** かな入力の設定には対応していない。
- **選んだ漢字そのものは送れない。** キーボードは文字ではなくキーしか送れないためである。候補をタップしたときは、読みを接続先に入れて変換させるので、接続先の変換結果が iPhone で選んだ候補と違うことがある。接続先の画面を見て、「空白」で候補を送るか、下の矢印キーの操作で選び直す。
- 入力モードは自動でそろえる。日本語キーボードで打ち始めると `かな` キーを、英語キーボードで打ち始めると `英数` キーを先に送る（設定 > 文字入力 >「日本語入力を自動で切り替える」）。
- 漢字や絵文字など、キーで打てない文字は送らない。入力欄に「送れない」と出る。
- 貼り付けボタンで、クリップボードの文字列を1文字ずつ打って送れる。対象は英数字と記号。

### 空白キー長押しの矢印キー

iPhone のキーボードで空白キーを長押ししたままなぞると、その向きの矢印キーを接続先に送る。

- 端まで行って指を置いたままにすると、その方向の矢印キーを打ち続ける。指を戻すか離すと止まる。
- 接続先で変換結果が未確定のときは、これで候補や文節を選べる。
- iPhone 側で変換中の文字があるときは、矢印キーは送らない。
- 設定 > 文字入力 >「空白キー長押しで矢印キー」でオフにできる。

### クリッカーモード

設定の一番上の「クリッカーモード」をオンにすると、画面が発表用に変わる。終了するときは、画面上部の接続先の名前を押して「クリッカーを終了」を選ぶ。

| 操作 | 動き |
|---|---|
| 上半分をタップ | 次のスライド |
| 下半分をタップ | 前のスライド |
| 中央の丸いボタンを押している間 | レーザーポインターを出し、iPhone を振った向きに動かす |

- スライド送りは、指を離したときに1回だけ送る。触れ始めた半分から出ずに離した場合に限る。押し続けても連打しない。
- 送るキーは「→」と「←」。設定の「スライド送りのキー」で PageDown／PageUp に変えられる。
- ポインターの感度は、接続先ごとに変えられる（接続先の名前を押して「感度…」）。

「ポインターの出し方」は、接続先ごとに選ぶ。

| 方式 | 押したとき／離したとき | 向いている場面 |
|---|---|---|
| PowerPoint（切り替え） | Mac は ⌘L／⌘A、Windows は Ctrl+L／Ctrl+A | PowerPoint のスライドショー（既定） |
| Ctrl＋左ボタン押しっぱなし | Ctrl と左ボタンを押す／離す | Windows の PowerPoint。Mac では右クリックになるので使わない |
| ポインタを動かすだけ | キーは送らない | Keynote や PDF など、マウスのポインタで指示する場合 |

## 設定

右上の歯車から開く。

| 区分 | 項目 |
|---|---|
| クリッカー | クリッカーモード、スライド送りのキー、ポインターの出し方、ポインターの感度 |
| （接続先）の速さ | ポインタの速さ、スクロールの速さ |
| トラックパッド | 加速、タップでクリック、スクロールの向きを反転、ボタンを押したときの振動 |
| スクロール | スクロール帯（右端／左端／なし）、帯の幅、スクロールの慣性 |
| 文字入力 | 日本語入力を自動で切り替える、空白キー長押しで矢印キー、カーソル移動の感度、入力内容のログ（診断用） |
| 新しい接続先の初期値 | ポインタの速さ、スクロールの速さ、キー配列、接続先の OS |

「接続先の管理」から接続先を選ぶと、名前、速さ、クリッカーの方式、キー配列（JIS／US）、接続先の OS を接続先ごとに変えられる。

## 困ったとき

| 症状 | 対処 |
|---|---|
| Windows で「その他のデバイス」になり、動かない | Windows と iPhone の両方で古い登録を消してから、ペアリングし直す（「つなぎ方」を参照） |
| 記号が違う文字になる | 接続先の設定で、キー配列の US と JIS を切り替える。macOS は、種類を選んでいない Bluetooth キーボードを US 配列として扱うので、Mac 向けは US にする |
| 英字を打つと日本語になる、またはその逆 | 設定 > 文字入力 >「日本語入力を自動で切り替える」がオンか確かめる。接続先側で手動で切り替えたあとは、一度キーボードの言語を切り替え直すとそろう |
| 変換結果が選んだ候補と違う | 仕様上の限界。「空白」か、空白キー長押しの矢印キーで選び直す |
| Mac につながらない | Mac の Bluetooth がオンか確かめ、アプリを起動し直す。それでも駄目なら `Tools/mac-connect` の `connect` を試す |
| ポインタの動きが少しカクつく | この Mac との通信は 30 ミリ秒ごとで、短くできなかった（[設計書](docs/design.md)の制約の節） |
| 起動に失敗する | iPhone がロックされていると、コマンドからの起動は失敗する。ロックを解除する |

## 制約

- 操作できるのは、アプリが前面にある間だけ。ロック中やバックグラウンドでは使えない。
- 接続先に表示される名前は iPhone の端末名になる。アプリからは変えられない。
- HID サービスの登録に、公開された仕様にない iOS の挙動を使っている（128 ビット形の UUID なら受理される）。iOS の更新で動かなくなる可能性がある。
- Windows で確かめたのは、接続、ポインタの移動、送り先の切り替えまで。キーボード、日本語入力、クリッカーは Windows では未確認。
- Mac の Bluetooth を入れ直したあとや、スリープから復帰したあとの再接続は未確認。

## 開発

```
iphone-mouse/
  README.md          この文書
  docs/design.md     設計と、実機で確かめたことの記録
  App/               iOS アプリ（project.yml、Sources）
  Packages/HIDCore/  画面や通信に依存しないロジックと単体テスト
  Tools/mac-connect/ Mac 用のコマンド（接続の補助、テストでの観測）
  scripts/           ビルド、インストール、起動、終了
  spike/             調査と測定に使ったコード（製品コードからは参照しない）
```

単体テスト：

```
cd Packages/HIDCore && swift test
```

実機テストでは、Mac 側の観測に `Tools/mac-connect` を使う（[Tools/mac-connect/README.md](Tools/mac-connect/README.md)）。

**自動テストで送った入力は、その時点で Mac の前面にあるアプリに届く。** 送ってよいキーの範囲と、文字入力のテストで接続先への入力を横取りする手順は、[設計書](docs/design.md)の「テストの安全規則」に従う。

診断のために打った内容をログに残したいときは、設定 > 文字入力 >「入力内容のログ（診断用）」をオンにする。既定はオフで、オフの間は打った文字はログに残らない。

## ライセンスと出典

HID over GATT の仕様をもとに独自に実装した。既存のオープンソース実装（`darwin-bt-remote`、AGPL-3.0）のコードは使っていない。
